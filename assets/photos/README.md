# Spare photos

The images from Leanne's shoot that aren't currently placed on the site. They
live here rather than in `public/` so they're versioned and ready to swap in,
without being deployed.

To use one: copy it into `public/images/` with a descriptive name (matching the
`<subject>-<print number>.jpg` convention used there) and point the page at it.

Numbers match the contact sheet: 2, 22, 37, 46, 53, 68, 74, 78, 94, 198, 203,
208, 307, 322. (118 is now on the contact page.)
